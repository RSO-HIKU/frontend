# HIKU Frontend

The HIKU frontend is a React Native mobile application built with Expo that provides users with an intuitive interface for exploring hiking trails, tracking peak ascents, and sharing their hiking achievements. It integrates with the HIKU microservices to display peak information, trail data, weather forecasts, and user logbooks with real-time updates. The app supports user authentication via Keycloak and runs on both Android and iOS platforms.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the app:
   ```bash
   npx expo start
   ```

3. Run on emulator or device:
   - Android: press `a` in the terminal
   - iOS: press `i` in the terminal
   - Expo Go: scan QR code with Expo Go app

For full documentation see: [Docs](./documentation.md)
